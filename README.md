# ZEST Programming Language

ZEST is a toy programming language written in Java to explore the fundamentals of compiler and interpreter design.

The project was created as a learning exercise to understand how modern programming languages work internally, from lexical analysis to parsing and Abstract Syntax Tree (AST) construction.

---

## Features

- Lexical analysis (Scanner/Lexer)
- Token generation
- Recursive descent parser
- Abstract Syntax Tree (AST)
- AST Printer
- Error reporting
- Modular Java implementation

---

## Project Structure

```
ZEST/
│
├── Scanner.java         # Converts source code into tokens
├── Token.java           # Token representation
├── TokenType.java       # Language token definitions
├── Expr.java            # Abstract Syntax Tree classes
├── GenerateAst.java     # Generates AST boilerplate
├── AstPrinter.java      # Prints the AST
├── ZEST.java            # Main program entry point
